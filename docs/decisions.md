# 关键决策

| 决策 | 触发问题 | 当前约束 | 再评估条件 |
| --- | --- | --- | --- |
| 先 PWA 验证后原生化 | 尚未确定日常体验 | 显著改变主流程的想法先做原型 | 新想法有稳定使用价值 |
| 本地优先 | 日常记录涉及个人内容 | 默认本地保存；主动 AI 请求明确例外 | 出现有证据的跨设备需求 |
| 一份记录源计算各页面 | 页面之间可能出现不同统计值 | 不维护独立演示统计 | 性能要求需要缓存时，先定义失效机制 |
| 周目标与日目标分开 | 固定日完成率不适用于每周几次 | 同时保留频率与测量值 | 用户计划类型改变 |
| 规则与界面分层 | UI 迭代容易影响统计 | 业务规则有独立测试 | 复杂度增长后按领域细分 |

决策不是永久不变的原则；修改时应补充触发证据与回归要求。
